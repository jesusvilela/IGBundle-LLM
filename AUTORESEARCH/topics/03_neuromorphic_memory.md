# Topic: Neuromorphic Memory Systems for AI

## Research Questions
1. What computational models of biological forgetting exist beyond exponential decay?
2. How do FitzHugh-Nagumo dynamics compare to Hodgkin-Huxley for modeling memory consolidation?
3. What is the state of the art in interference-based forgetting for AI memory systems?
4. How do Method of Loci / memory palace techniques map to computational retrieval architectures?
5. What work exists on frequency-selective memory decay (FFT-based or wavelet-based)?
6. How do Kolmogorov-Arnold Networks (KAN) compare to MLPs for learning adaptive decay curves?
7. What role does Gabor analysis play in memory interference modeling?

## Keywords
neuromorphic computing, biological memory, forgetting curve, Ebbinghaus, FitzHugh-Nagumo,
memory consolidation, reconsolidation, retroactive interference, proactive interference,
method of loci, complementary learning systems, hippocampal replay, schema formation,
KAN, Kolmogorov-Arnold, Gabor transform, spectral memory
