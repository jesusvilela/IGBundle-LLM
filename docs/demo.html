Research code, not a hosted demo

This page does not offer a validated hosted model or inference service.

IGBundle remains an experimental research prototype. Existing checkpoints are historical artifacts; current evidence does not establish improved task performance or learned hyperbolicity. See the correction notice before interpreting older documentation or model cards.

Inspect the source

The repository contains the implementation, tests, research configurations, and published evidence summaries. Cloning the repository does not download a base model or start training.

git clone https://github.com/jesusvilela/IGBundle-LLM.git
cd IGBundle-LLM

Before installing dependencies or downloading model weights, review the repository license, base-model terms, checkpoint provenance, environment requirements, and the limitations in the README and evidence page. Historical training commands, hardware figures, or launcher instructions should not be treated as verified support.

Reproduction standard

The evidence arithmetic runs offline with the Python standard library, without installing ML dependencies or loading models:

python scripts/verify_evidence.py

This recomputes stored measurements and checks site links. It does not repeat model inference or verify the historical graders. The README lists the separately bounded CPU operator checks and legacy implementation limitations.

scripts/inspect_gguf.py can inspect a local GGUF's metadata and tensor directory with a 32 MiB read cap, without loading its weights. Its prefix digest is not a full-model checksum. Do not equate a nearby adapter file or a generated topology image with a verified geometry-aware runtime.

For a meaningful comparison, keep data splits, model loading, decoding, parameter budget, layer coverage, and training budget matched; isolate the geometric component; use multiple seeds; and publish exact checkpoint provenance and task-level outputs. Geometry checks alone are not a substitute for downstream evaluation.
