Geometric structure as a research hypothesis

IGBundle explores information-geometric operations and fiber-structured adapters for language models. Current evidence does not establish improved task performance or learned hyperbolicity.

Research design

Hn

Poincare-ball coordinates

The design uses hyperbolic coordinates as a candidate representation for hierarchical structure. This is a modeling hypothesis, not a finding that the trained model learned semantic hierarchy.

π

Categorical fiber components

Categorical components provide a structured adapter parameterization. Their presence does not establish fiber-bundle semantics or global consistency in model behavior.

κ

Geometric operators

The current Poincare distance kernel has analytic and gradient regression checks. Historical “6/6” diagnostics are not a certification of this code or of learned geometry.
