Evidence, scope, and limitations

Updated 31 October 2026 · IGBundle is experimental research, not a validated model release.

Bottom line: The fiber-structured geometric-adapter idea remains an open hypothesis. Available results do not demonstrate a general task-performance advantage or learned hyperbolicity. Older numerical claims were withdrawn; see the correction notice.

1. October 2026 local multi-benchmark evaluation

A local run on 27 October compared base Qwen2.5-7B, an exported merged cp300 checkpoint, and a reconstructed adapter composite. Evaluation used greedy decoding on fixed subsets ranging from 8 to 98 examples. The custom weighted index is descriptive, not a standardized benchmark and not a statistical test.

None of the per-task paired comparisons was significant. For the reconstructed composite vs cp300, recomputed exact McNemar p-values were 0.625–1.00 (0.63–1.00 rounded in the historical table). The composite was assembled post hoc and was not the original trained checkpoint; different checkpoint assembly and quantization/loading paths prevent isolating a geometric effect. Higher point estimates on some small subsets are not confirmation of benefit.

2. September 2026 paired token-NLL probe

On 24 examples reported as held out, with 64 tokens scored per example, mean token NLL was 2.3188 for the frozen base, 1.9352 for geometric adapter A, and 0.8187 for vanilla-LoRA control B. B had lower NLL on all 24 pairs. Mean paired difference A − B was 1.1165 (95% paired t interval 0.9144–1.3186). The reproducible two-sided sign-test p-value is 1.1921 × 10−7, distinct from the historical t-test.

This probe is not task accuracy and does not isolate geometry: A had 4,160,713 trainable parameters and one geometric layer; B had 585,728 parameters and 13 LoRA layers. The published file omits prompt text.

3. Historical diagnostics are not a mathematical certification

A historical file reports 6/6 checks passed, but lacks an immutable source/checkpoint binding. The inspected audit loader allows absent weights (random initialization) and partial state loads. Its transport check is coordinate displacement; its energy check uses squared coordinate norm, not a Hamiltonian. This record is retained for transparency, not as verified operator faithfulness.

For the historical log-determinant proxy with g(x) = λ(x)G and fixed λ, spatial finite differences cancel the position-independent log det G. At fixed coordinates that proxy cannot detect changes in G. Coordinates can still change with training; this does not prove that the actual metric is flat or that every curvature estimator is weight-invariant. The current public branch and historical experimental branch are distinct.

6. Fail-closed default-adapter restoration

Five public HF entry points now require complete default-adapter state. The shared loader checks exact tensor names, shapes, finite values and conversion overflow before copying any adapter tensors. It reads tensor-only state on CPU and does not retry unrestricted pickle loading. Declared PEFT loading errors propagate.

Tiny synthetic checkpoints cover round-trip restoration, rejection without partial mutation, unchanged base weights, and execution of a restored adapter with gradients. Entry-point checks use isolated functions and stubs, not real Transformers/PEFT loading. Partial or differently prefixed historical checkpoints now fail explicitly.

This does not identify a base model, validate archived companion weights, implement a GGUF geometry backend, or establish hypercomplex execution. Full-state mode restores only default-adapter tensors. Exact contract, file requirements and remaining limits.

7. Demo evidence and descriptive telemetry

The public app no longer substitutes synthetic training curves, hard-coded ablation accuracies or invented statistics for missing evidence. Training and ablation panels now explicitly say unavailable. Withdrawn performance, significance and efficiency claims were removed from its UI.

Sigma is a Gaussian standard deviation, not curvature. The heatmap shows categorical probabilities, not pairwise affinities. Entropy and the arbitrary sigma interval counter are descriptive, not geometric faithfulness or quality scores. Missing telemetry is unavailable, not zero.

Observation-weighted summaries support varying decode lengths. Capture retains at most 4,096 sigma samples plus fixed-size summaries; the histogram is labeled as a prefix sample. Repeated context may be counted again. Requests are serialized and capture resets for each request.

Headless checks render tiny-array plots and verify aggregation, missing-data behavior, bounded storage and hook cleanup. A real Gradio interface is constructed with a stubbed model and intercepted launch; no server or inference backend is tested. Exact scope and normalization policy.

Exporter preflight: the public export entry point now requires explicit LoRA-only scope, an exact base identifier, a trusted converter and fresh output paths. Its dry run imports no model backend. Mocked orchestration and bounded GGUF directory checks do not certify real conversion or geometric execution.

8. Parameter display, not topology

The standalone renderer now shows a deterministic prefix of one explicitly selected input-projection matrix. Missing, ambiguous or malformed state fails instead of producing a random scaffold. Filenames no longer select geometry; semantic node metadata is rejected.

The self-contained HTML/SVG embeds a source-file hash, shape, dtype, prefix extent and color scale. Input files are capped at 64 MiB, selected matrices at 4,194,304 values, and plots at 64 x 64 values (32 x 32 in lite mode). This is a trusted-local-file utility, not a deserialization sandbox or proof of complete restoration.

No topology, learned curvature, hypercomplex multiplication or model benefit follows from these parameter values.

9. Exact algebra reference

An independent Cayley-Dickson reference checks unit, conjugation, norm composition and alternativity in dimensions 1, 2, 4 and 8. Checks expand exact coefficients rather than sampling floating-point inputs. Associativity fails for the octonions: (e1 e2) e4 = e7, but e1 (e2 e4) = -e7 in the declared convention.

Exact certificate. This is not an IGBundle integration, hyperbolic metric, checkpoint certification or task result.

10. Tiny real-backend composition

Hosted CPU checks use a random two-layer, width-16 Qwen2 with PyTorch 2.6.0, Transformers 4.48.3, PEFT 0.14.0 and Accelerate 1.2.1. Identity wrapping, separate PEFT save/reload, strict adapter restoration, gradients and cached generation are exercised without pretrained downloads.

Restored nonzero adapter state affects logits without changing base/LoRA tensors. This is not a historical-checkpoint, accuracy, quantized-backend, full-app or GGUF certificate.

11. Exact declared-LoRA restoration

Six public load/merge paths now check exact default-LoRA keys, shapes, finite values and restored values. Partial state and wrapper-prefix mismatches fail explicitly.

Tiny real PEFT checks cover wrapped saves with matching wrapper structure. This is post-load verification, not rollback or historical checkpoint certification. Unsloth remains untested.

12. Hyperbolic transport: rotation and duality

The archived scale-only Poincare transport preserves vector length but returns identity around every closed loop. A new opt-in reference includes the missing gyration rotation and a distinct cotangent map for momentum.

On the prescribed K=-1 geodesic triangle (0,0) to (.3,0) to (0,.4) to (0,0), the tangent rotates by -0.238857852 radians, agreeing with an independent hyperboloid calculation and the negative angle defect. Scale-only transport returns zero rotation.

Numerical witness and source fingerprints, dual-map derivation and bounded test scope. This reference is not wired into either adapter or GGUF and does not certify the archived integrator, learned geometry or task benefit.

13. Legacy adapter execution

The separate GeometricIGBundleAdapter no longer constructs an unused rank-four metric that caused multi-token forward calls to fail. The repaired helper preserves the original coordinate smoothing: s_0 = x_0, s_t = x_t - 0.1 * (x_t - x_(t-1)). It uses the original predecessor, not the already smoothed value. Parameter names, shapes and initialization are unchanged.

Six tiny hosted CPU tests check identity/nonzero execution, gradients, causal prefixes and exact strict module-state roundtrip. The forward path does not call its neural connection or transport methods. This is coordinate blending, not parallel transport; the diagonal metric scaling and Euclidean refinement do not certify natural gradients or a Riemannian mean.

Independent one-token smoothing calls need previous-coordinate history to match a full sequence. Cached generation, historical restoration, default-loader coverage for this legacy class, auxiliary losses, training and general numerical stability remain unvalidated. Reproduced failure, exact hosted test scope and limits.

14. Tiny native GGUF execution

Two synthetic F32 Qwen2 files, with 17,136 and 35,296 parameters, execute in pinned native llama.cpp on hosted CPU. They exercise grouped-query attention, tied/untied output weights and supplied token-ID sequences. Full/incremental logits match an independent PyTorch reference at rtol=1e-4, atol=1e-5; the largest observed absolute error was 1.79e-7, and all argmax IDs matched.

Malformed Q/K tensor shapes fail both directory checks and native loading. Negating only output weights instead leaves the directory report unchanged except the filename, but changes native logits by 0.77686. Complete file hashes differ: a prefix hash is not a fingerprint of the executed model weights. Recorded results and full synthetic-file hashes.

No archived exports, public converter, text tokenizer, quantized kernels or geometric/hypercomplex adapter are exercised. This is a tiny F32 runtime control, not learned geometry or a task-performance result. Exact configuration, source/run binding and exclusions.

15. Archived companion metadata

A restricted, non-executing ZIP/pickle reader records 226 tensor descriptors across four archived companions, reading 52,399 metadata bytes in a complete pass and opening no tensor-storage members. Genuine tiny PyTorch saves independently exercise dtype, shape, stride, alias, offset and module-version decoding.

The ARC package has a direct hidden-width mismatch: arc_adapter.pt expects and returns width 3584, while the surviving ARC GGUF has width 896. The standalone projector maps 1152 visual features to a 896-wide adapter bottleneck. Its eleven shapes match the embedded projector, but its bfloat16 dtype differs from the adapter's float32. This is not a compatible-base or vision-alignment certificate.

The dist and varied adapters also declare width 3584. Matching core dimensions do not prove restoration: the inspected dist runner's defaults disable modules corresponding to 17 saved vision and five geodesic-attention keys, and loading is non-strict. No archived weights were executed or changed. Full metadata and source excerpts.

These fingerprints exclude tensor values. Storage checksums, trained-state provenance, geometric laws and model benefit remain unverified. Exact inspection profile, hosted controls and compatibility analysis.

16. What a stronger test needs

A causal evaluation should match parameter budget and layer placement; compare against a vanilla adapter under the same data, objective, optimizer budget, decoding, and hardware; isolate the geometric operator; use multiple seeds and fixed task splits; and publish exact checkpoint provenance with per-task outputs. Operator diagnostics should remain distinct from downstream outcomes.

No efficiency claim is made. The repository does not currently provide a matched, reproducible training-time, inference-latency, or memory comparison supporting earlier percentages.
